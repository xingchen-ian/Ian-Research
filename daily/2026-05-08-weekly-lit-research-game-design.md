# Weekly Literature Research — Game Design (May 8, 2026)

**Focus:** Game Mechanics from Life Experience | MDA Framework | AI-Assisted Game Development

## 1. Game Mechanics from Life Experience (Embodied Cognition)

**Key Insights:**
- **Embodied cognition** emphasizes designing mechanics that resonate with players' real-life sensorimotor experiences
- **Core principles:** 
  - Control mapping that leverages innate bodily experiences
  - Structural isomorphism between real and simulated actions
  - Clear feedback loops
  - Active interaction over passive viewing
- **Applications:** VR serious games for skill training, educational games using full-body movement for abstract concepts
- Research shows players construct knowledge schema through external perceptions derived from bodily actions

**Notable Sources:**
- Frontiers in VR game design research
- "VR Serious Game Design Based on Embodied Cognition Theory" (ResearchGate)
- "From Ecology to Emotion: How Students Translate Real-World Knowledge Into Game Mechanics" (2025)

## 2. MDA Framework (Mechanics, Dynamics, Aesthetics)

**Recent Developments:**

- **"How the MDA Framework Enhances Microlearning Game Design"** (April 2025) — applies MDA to educational microlearning contexts
- MDA remains a foundational framework for analyzing how games create engaging experiences through the bridge of dynamics between mechanics and aesthetics

## 3. AI-Assisted Game Development (Procedural Generation)

**Key ML Approaches:**
- **Deep Learning (GANs, VAEs, LSTMs):** Generating levels, textures, 3D objects, character models
- **Reinforcement Learning (RL):** Training agents to design game content; framing level design as sequential decision-making
- **LLMs & Generative AI:** Creating interactive fiction, quests, storylines, and game levels from text prompts

**Research Frontiers:**
- Combining traditional PCG with ML for coherence and playability
- Learning from small datasets
- Balancing automation with human artistic control
- "Deep Learning for PCG of 2D Video Game Levels" (ResearchGate)
- "Procedural Content Generation in Games: A Survey with Insights on Emerging LLM Integration" (ResearchGate)

---

## Summary

This week's research confirms three converging trends in game design:

1. **Embodied design** — mechanics rooted in real physical experience (especially in VR/AR)
2. **Structured frameworks** (MDA) — being applied beyond entertainment to education and microlearning
3. **AI-augmented creation** — LLMs and ML transforming procedural content generation, but with ongoing challenges in quality control
